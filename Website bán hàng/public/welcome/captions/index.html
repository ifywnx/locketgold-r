Cách dùng script với Shadowrocket
  1. Chọn caption rồi xuất script. File chỉ thay danh sách caption và giữ các mục mặc định từ máy chủ; không thay Gold, DNS hoặc thanh toán.
  2. Đây là file dành cho quản trị viên: đưa JS lên địa chỉ HTTPS do bạn quản lý. File tải xuống chưa tự cài vào Shadowrocket.
  3. Trong bản sao cấu hình đang dùng, thay script-path của quy tắc Firebase Remote Config bằng URL script mới. Không chạy đồng thời quy tắc caption cũ và mới trên cùng phản hồi.
  4. Bật bản thử, mở lại Locket và kiểm tra. Muốn quay lại: khôi phục script-path cũ rồi cập nhật script. Locket có thể lưu cache, nên không hứa thay đổi ngay lập tức.

Script này chỉ chỉnh caption. Các tuỳ chỉnh khác trong script Remote Config cũ sẽ không được áp dụng khi thay nó. Chưa được thử trực tiếp trên iPhone.

Sticker hoặc caption không hiện?

Kiểm tra đúng cấu hình, module và tin cậy chứng chỉ. Chỉ bật một quy tắc Remote Config. Nếu lỗi xuất hiện sau khi đổi script, quay lại bản trước. Ghi phiên bản Locket và chụp lỗi; không cần xoá ứng dụng. DNS không tự thêm sticker.
